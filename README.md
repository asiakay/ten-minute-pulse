# Ten-Minute Pulse

A 10-minute data project that captures a real-time sentiment snapshot using sample text or news headlines.

## Quick Start

1. Clone this repository:
   ```bash
   git clone https://github.com/YOURUSERNAME/ten-minute-pulse.git
   cd ten-minute-pulse
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the script:
   ```bash
   python main.py
   ```

## Output
The program prints sentiment counts and saves a `mood_map.png` bar chart visualizing the community mood.
